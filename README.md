# Modbus 通讯助手

一个使用 Qt Widgets 编写的 Modbus RTU、ASCII、TCP 与内部虚拟通道主站/从站调试工具。

完整的安装、使用、构建和发布说明请查看：[PROJECT_DOCUMENTATION.md](PROJECT_DOCUMENTATION.md)。

## 功能

- 串口扫描、打开/关闭以及常用串口参数配置
- 内置免驱动虚拟通道，可让本机多个软件实例直接进行 Modbus RTU 主从通讯
- 主站/从站模式一键切换
- 支持 Modbus RTU、Modbus ASCII、Modbus TCP 与内部虚拟通道
- 支持功能码 `01`、`02`、`03`、`04`、`05`、`06`、`0F`、`10`
- RTU 自动生成与校验 CRC16，ASCII 自动生成与校验 LRC，TCP 自动处理 MBAP 事务头
- 寄存器/线圈结果解析，支持十进制、十六进制与二进制显示
- 定时轮询、响应超时、Modbus 异常响应解析
- 原始十六进制报文发送，可选自动追加 CRC
- 带时间戳与方向标记的通讯日志
- 自动保存常用配置
- 支持亮色和暗色工业主题，可记住上次选择
- 支持软件多开，可同时调试多个设备
- 数据解析支持表格模式和面板模式
- 主站增加趋势曲线页，可显示轮询读取的寄存器/位状态历史
- 趋势曲线支持暂停、清空、历史采样点数设置和鼠标悬停读数
- 线圈可使用 ON/OFF 指示灯显示，寄存器可使用多行多列数值框显示；从站面板中可直接点击或输入修改
- 解析结果按 PLC 常用编号显示：线圈 `00001`、离散输入 `10001`、输入寄存器 `30001`、保持寄存器 `40001`
- 从站模式内置线圈、离散输入、保持寄存器和输入寄存器数据区，可直接编辑并自动响应主站
- 从站支持自动数据仿真：寄存器可生成随机数、正弦波、方波、三角波、递增计数、锯齿波、高斯热噪声、随机游走、脉冲和阻尼正弦，位数据可生成随机状态、流水灯、闪烁和交替状态

## 构建

需要 Qt 5.15+ 或 Qt 6.x，并安装 `Serial Port` 模块。

1. 使用 Qt Creator 打开根目录的 `CMakeLists.txt`
2. 选择已安装 Qt SerialPort 的 Desktop Kit
3. 配置并运行项目

命令行构建示例：

```powershell
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH="你的Qt安装目录"
cmake --build build
```

## 使用提示

- 请求中的起始地址仍按 Modbus 协议从 `0` 开始；解析结果会自动换算为 PLC 常用地址，例如协议地址 `0` 显示为保持寄存器 `40001`。
- 功能码 `0F` 的写入数据使用空格或逗号分隔的 `0/1`。
- 功能码 `10` 的写入数据使用空格或逗号分隔的十进制或 `0x` 十六进制数值。
- 原始报文输入区接受带或不带空格的十六进制字符串。
- 切换到从站模式后，先设置本站地址和数据区内容，再打开串口等待主站请求。
- 从站“自动数据”直接使用左侧的显示起始地址和显示数量，固定每 500 ms 更新一次，波形周期固定为 10 s；停止后保留最后生成值，“恢复手动值”可恢复启用前的范围快照。
- 自动仿真运行期间，仿真范围内的表格和面板编辑会被锁定；主站写入仍会响应，但下一次仿真更新会重新覆盖该范围。
- 主站成功读取功能码 `01`～`04` 后，切换到“趋势曲线”页即可查看历史变化；更换读取地址后会自动开始新的曲线组。
- 内部虚拟通道仅供本机的 Modbus 通讯助手实例互联，不会创建系统 `COMx` 端口，也不能被第三方串口软件识别。
- 使用内部虚拟通道时，先在一个从站实例中输入通道名称并点击“创建通道”，再在主站实例中输入相同名称并点击“加入通道”。
