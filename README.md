# Modbus 通讯助手

一个使用 Qt Widgets 编写的 Modbus RTU、ASCII 与 TCP 主站/从站调试工具。

## 功能

- 串口扫描、打开/关闭以及常用串口参数配置
- 主站/从站模式一键切换
- 支持 Modbus RTU、Modbus ASCII 与 Modbus TCP
- 支持功能码 `01`、`02`、`03`、`04`、`05`、`06`、`0F`、`10`
- RTU 自动生成与校验 CRC16，ASCII 自动生成与校验 LRC，TCP 自动处理 MBAP 事务头
- 寄存器/线圈结果解析，支持十进制、十六进制与二进制显示
- 定时轮询、响应超时、Modbus 异常响应解析
- 原始十六进制报文发送，可选自动追加 CRC
- 带时间戳与方向标记的通讯日志
- 自动保存常用配置
- 从站模式内置线圈、离散输入、保持寄存器和输入寄存器数据区，可直接编辑并自动响应主站

## 构建

需要 Qt 5.15+ 或 Qt 6.x，并安装 `Serial Port` 模块。

1. 使用 Qt Creator 打开根目录的 `CMakeLists.txt`
2. 选择已安装 Qt SerialPort 的 Desktop Kit
3. 配置并运行项目

命令行构建示例：

```powershell
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH="你的Qt安装目录"
cmake --build build
```

## 使用提示

- Modbus 地址按协议从 `0` 开始；若设备手册写的是 `40001`，通常应输入地址 `0`。
- 功能码 `0F` 的写入数据使用空格或逗号分隔的 `0/1`。
- 功能码 `10` 的写入数据使用空格或逗号分隔的十进制或 `0x` 十六进制数值。
- 原始报文输入区接受带或不带空格的十六进制字符串。
- 切换到从站模式后，先设置本站地址和数据区内容，再打开串口等待主站请求。
