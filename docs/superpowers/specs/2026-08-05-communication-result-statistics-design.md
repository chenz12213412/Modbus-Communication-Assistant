# 通讯成功失败统计设计

## 目标

在软件底部状态栏右侧增加通讯结果统计，帮助用户快速判断当前通讯质量。统计同时覆盖主站和从站模式，并与现有 TX/RX 计数并列显示。

## 界面

右下角新增独立标签，显示格式为：

`成功 0 · 失败 0 · 成功率 --`

发生通讯后，成功率按 `成功数 / (成功数 + 失败数)` 计算并显示整数百分比。统计标签保持紧凑，不挤占左侧状态信息。

## 统计口径

### 主站成功

- 收到并完成解析的有效 Modbus 响应。
- 原始报文模式收到通过协议格式和校验检查的有效响应。

### 主站失败

- 请求发送失败。
- 等待响应超时。
- TCP MBAP、ASCII LRC 或 RTU CRC 校验失败。
- 从站地址、事务标识、功能码、响应长度或写入回显不匹配。
- 收到 Modbus 异常响应。

### 从站成功

- 成功发送一次有效响应。
- 广播写请求执行成功但无需响应时，计为一次成功。

### 从站失败

- 收到格式、校验、地址范围或参数非法的请求。
- 从站响应写入传输层失败。

连接配置错误、未打开端口、用户输入格式错误和普通界面操作不计入通讯失败，因为这些情况尚未形成一次实际通讯事务。

## 状态管理

主窗口维护成功数和失败数，并通过统一辅助函数更新标签，避免各通讯分支重复拼接文本。每次通讯事务只记录一次最终结果，防止同一错误同时在校验和解析阶段重复计数。

点击“清空日志”时，同时清零 TX、RX、成功数和失败数。程序重新连接或切换主从站时不自动清零，便于观察整个运行期间的累计结果。

## 验证

- 有效主站响应增加成功数。
- 响应超时和无效响应分别只增加一次失败数。
- 从站成功响应增加成功数，发送失败增加失败数。
- 清空日志后所有计数归零，成功率恢复为 `--`。
- 亮色和暗色主题下统计文字均清晰可见。
