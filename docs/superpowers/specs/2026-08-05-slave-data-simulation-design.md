# 从站数据仿真设计

## 目标

从站模式下将“数据解析”明确呈现为“数据仿真”，在保留手动编辑能力的基础上，为当前选中的数据区提供自动数据生成。自动仿真仅影响指定地址范围，不修改其他数据区，也不改变主站模式的解析和趋势曲线行为。

## 界面与工作流

- 切换为从站后，右侧页签和区域标题显示“数据仿真”；切回主站后恢复“数据解析”。
- 从站左侧增加“自动数据”分组，包含启用开关、仿真模式、更新周期、起始地址、仿真数量和模式参数。
- 仿真数据区始终跟随当前“数据区”选择：线圈、离散输入、保持寄存器或输入寄存器。
- 仿真起始地址和数量默认同步当前显示范围，用户可以单独修改，范围必须位于 `0..65535`。
- 提供“重置相位”和“恢复手动值”命令。“恢复手动值”停止自动仿真，并恢复启用仿真前保存的范围数据。
- 启用仿真后，仿真范围内的数据编辑锁定；范围外仍可手动编辑。关闭仿真后保留最后生成的数据并恢复编辑。

## 仿真模式

### 线圈与离散输入

- 随机状态：每个点按配置概率独立生成 `0/1`。
- 流水灯：每次更新只点亮一个位置，到边界后按配置方向循环。
- 方波/闪烁：指定范围在全灭和全亮之间切换。
- 交替翻转：奇偶地址交替为 `1/0`，每次更新互换。
- 全部接通：范围内持续为 `1`。
- 全部断开：范围内持续为 `0`。

线圈模式参数包括随机接通概率和流水灯方向。方波、交替翻转、全开、全关只使用更新周期。

### 保持寄存器与输入寄存器

- 随机数：每个点在最小值与最大值之间独立随机。
- 正弦波：在最小值与最大值之间按周期平滑变化，相邻地址使用小幅相位偏移，便于多点趋势观察。
- 方波：在最小值与最大值之间按半周期切换。
- 三角波：在最小值与最大值之间线性上升和下降。
- 递增计数：从最小值按步长递增，超过最大值后回绕。
- 锯齿波：在一个周期内线性递增，到周期末回到最小值。

寄存器公共参数为最小值、最大值和波形周期；递增计数额外使用步长。所有结果舍入并限制在 `0..65535`。

## 数据与时间模型

- 使用独立 `QTimer` 驱动从站仿真，不复用主站轮询定时器。
- 仿真引擎按累计 tick 和配置计算结果，生成逻辑与界面分离，便于单元测试。
- 更新周期范围为 `50..60000 ms`，默认 `500 ms`。
- 波形周期不得短于两次更新周期；界面在参数冲突时自动抬高周期并显示提示。
- 切换数据区、地址范围或模式时重置相位，避免旧模式状态污染新数据。
- 程序切换回主站或关闭窗口时自动停止仿真定时器。

## 手动写入与通讯写入

- 启用仿真时，当前仿真范围内的表格、寄存器框和线圈按钮不可编辑，工具提示说明该地址由自动仿真控制。
- Modbus 主站写入请求仍按协议执行并返回成功；若地址位于仿真范围内，该值会在下一次仿真更新时被当前模式覆盖。
- 仿真范围外的手动编辑与通讯写入保持现有行为。
- 自动生成只改变从站数据区，不伪造 TX/RX 通讯日志；实际请求和响应继续记录日志。

## 状态与持久化

- 保存上次使用的仿真模式、更新周期、范围和各模式参数。
- 出于可预期性，软件重新启动后不自动启用仿真，用户必须手动开启。
- 状态栏显示启用、停止、重置、范围错误和参数自动修正信息。

## 代码边界

- 新增独立的 `SlaveDataSimulator`，负责参数校验和单次数据生成，不依赖 QWidget。
- `MainWindow` 负责控件、定时器、数据区选择和将生成结果写入现有四个数据向量。
- 现有 Modbus 从站请求处理继续读取同一组数据向量，不增加第二份运行时数据源。

## 测试范围

- 所有位模式输出只能为 `0/1`，流水灯在范围内循环且方向正确。
- 所有寄存器模式输出位于最小值和最大值之间，周期边界和回绕正确。
- 无效范围、反向最小/最大值和过短周期得到明确校验结果。
- 自动仿真只更新当前数据区和指定范围。
- 启用、停止、恢复手动值、切换数据区和切换主从模式的状态正确。
- 主站通过 RTU、ASCII、TCP 或内部虚拟通道读取时能获得最新仿真值。
- 亮色和暗色主题下控件无重叠，下拉框和数值输入保持现有工业风格。

## 非目标

- 不生成脚本化场景、CSV 回放或跨数据区联动。
- 不模拟设备故障码、通讯延迟或丢包。
- 不在主站模式自动修改解析结果。
